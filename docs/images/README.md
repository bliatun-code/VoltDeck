# VoltDeck example images

The menu, configuration and diagnostics images show VoltDeck in the ETHOS
26.1.2 X20RS simulator. Read the current status banner in diagnostics; a passing
airborne gate alone does not qualify a flight.

The Home-menu image shows all five choices. Flight-log images include the
bottom-right Diagnostics button; the empty-log example shows where to find it
before a flight has been recorded. RTN returns from either view to Dashboard.

The layout examples use illustrative values rather than recorded flights.
The battery-check dialogs illustrate manual confirmation and a blocked
consumption reading; read the stated difference and its direction before
accepting a counter.

The four pack-transition images show a paused session, its retained last log,
a new qualifying session and the next qualified session. The example count
stays at 3 until that next flight qualifies, then becomes 4.

See [the illustrated guide](../Configuration.md) and
[the Norwegian guide](../Konfigurasjon-norsk.md) for settings and limitations.
The Ultimate AMR model picture is example artwork used with permission.
It is optional and is not part of the installed widget. See [NOTICE](../../NOTICE.md).
